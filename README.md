# Shell / Bash Darslari va DevOps Amaliyotlari

Ushbu repozitoriy Linux va Bash bo'yicha amaliy skriptlar to'plamini o'z ichiga oladi.

## 📂 Skriptlar tarkibi

| Fayl | Mavzu / Tavsif |
| :--- | :--- |
| `arrays.sh` | Massivlar (Arrays), indekslar va massiv bo'ylab sikl |
| `string_manipulation.sh` | Satr uzunligi, substring kesish, matn almashtirish |
| `parameter_expansion.sh` | Default qiymatlar (`${var:-default}`), prefiks/sufiks ajratish |
| `functions.sh` | Funksiyalar, status kodlari va rangli loglar |
| `error_handling.sh` | Xavfsiz Bash (`set -euo pipefail`), `trap` mexanizmi |
| `system_monitor.sh` | Tizim resurslari (RAM, Disk, CPU) monitoringi |

## 🚀 Ishga tushirish

```bash
chmod +x <skript_nomi>.sh
./<skript_nomi>.sh
```
